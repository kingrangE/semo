# 세모-세종대학교의 모든 것
> 제 11회 SWAI 해커톤 은상 수상작(코드 복구)

## 개요
세종대학교와 관련된 파편화된 정보를 모아 RAG기반의 챗봇으로 응답을 제공하는 서비스입니다.

### 문제 
세모는 파편화된 정보의 문제를 해결하고자 개발했습니다.
세종대학교는 [공식 홈페이지](https://www.sejong.ac.kr/kor/index.do), [비교과 활동 페이지(두드림)](https://do.sejong.ac.kr/), [취업 정보 페이지(유드림)](https://udream.sejong.ac.kr/) 등 다양한 페이지에 정보가 산재되어 있습니다.
이로 인해 학생들은 매일 여러 사이트를 확인하는 번거로움을 겪고, 정보를 놓치는 경우가 늘어납니다.

세모는 이 문제를 해결하기 위해 개발했습니다.

### 해결방안
1. 정보 수집 : Airflow 일 Batch를 수행하며, 3개의 페이지에서 제공하는 정보를 크롤링하여 제공합니다.
2. 제공 : 취합한 정보를 아래 두 가지 방식으로 제공합니다.
    1. 챗봇 : 유저의 질문에 응답하는 방식으로 최신 상황을 공유합니다.
    2. UI : 사이트 메인 화면에 현재 신청할 수 있는 비교과 프로그램 / 취업 정보 등 유효한 주요 사항들을 모아서 제공합니다.

### 기대효과
1. 학생들이 학사 일정을 놓치는 문제를 최소화합니다.
2. 학생들이 참가할 수 있는 비교과 프로그램을 쉽게 접근할 수 있도록 함으로써 학생들의 참여를 유도합니다.
3. 학생들에게 취업 정보를 제공하며 교내 취업률 향상에 기여합니다.

### 향후 계획
1. 기존 해커톤 수상작과 마찬가지로, 연구실 정보 또한 취합해서 제공할 예정입니다.
    - 이를 통해, 학생들이 연구에 보다 쉽게 접근할 수 있도록 하고 교내 연구력 향상에 기여할 예정입니다.

2. 세종대 이외에도 다양한 학교를 대상으로 서비스해볼 예정입니다.
